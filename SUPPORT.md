# Support

## Bugs

Use the repository **Bug report** issue template. Please include:

- RealityLint version;
- operating system and Python version;
- minimal README/repository structure that reproduces the problem;
- expected and actual result.

## New checks

Use the **Rule request** issue template and describe a claim that can be verified deterministically from repository files.

## Security

Do **not** open a public issue for a vulnerability that could put users at risk. Follow [SECURITY.md](SECURITY.md).

## Русский

Для ошибок используйте шаблон **Bug report** и приложите версию RealityLint, ОС/Python, минимальный пример и ожидаемый результат.

Для новой проверки используйте **Rule request**. Хорошее правило должно проверяться детерминированно по локальным файлам репозитория.

Уязвимости не публикуйте в открытых issue — используйте инструкции из [SECURITY.md](SECURITY.md).
