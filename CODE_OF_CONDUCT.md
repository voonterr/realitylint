# Code of Conduct

RealityLint aims to be a practical and welcoming open-source project.

Be respectful, discuss code and ideas rather than people, assume good intent where reasonable, and keep technical criticism specific and actionable. Harassment, discrimination, threats, doxxing, spam, and deliberately disruptive behavior are not acceptable.

For moderation or sensitive conduct concerns, contact the maintainer privately through the contact method listed on [@voonterr's GitHub profile](https://github.com/voonterr).

## Русский

RealityLint — открытый проект, в котором ожидается уважительное профессиональное общение.

Обсуждайте код и идеи, а не личности. Техническая критика должна быть конкретной и полезной. Оскорбления, дискриминация, угрозы, публикация чужих личных данных, спам и намеренный саботаж обсуждений недопустимы.

По чувствительным вопросам лучше связаться с автором приватно через контакты в профиле [@voonterr](https://github.com/voonterr).
